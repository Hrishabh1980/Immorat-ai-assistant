Immorat – Personal Assistant (HTML & JavaScript)

Immorat is a lightweight web-based personal assistant built using only HTML and JavaScript.
It is designed to perform basic assistant tasks directly in the browser without any backend or external frameworks.

Features

🗣️ Interactive assistant interface
⚡ Fast & lightweight (no libraries used)
🌐 Runs entirely in the browser
🧠 Handles predefined commands and responses
🎯 Beginner-friendly project structure


Tech Stack

HTML – Structure & layout

JavaScript – Logic & interactivity

No frameworks, no backend, no APIs — just pure web basics.
